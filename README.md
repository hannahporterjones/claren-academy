# Claren Academy — Landing Page

Static landing page for Claren Academy.

## Running locally

No build step — just serve the folder.

```bash
python3 -m http.server 4100
```

Then open http://localhost:4100/

## Files

- `index.html` — the landing page
- `fonts/` — web fonts
- `*.png` / `*.jpg` / `*.webp` / `*.svg` — images and logos

## Key links

- Enroll / course buttons → `https://claren.thinkific.com/hub`
- Newsletter sign-up → HubSpot form (pre-fills email via query param)
- "Try for free" → `https://www.claren.law/sign-up`
